# Portfolio [![Commit Status](https://github.com/LegendarySpork9/Portfolio/actions/workflows/Commit.yml/badge.svg?event=push)](https://github.com/LegendarySpork9/Portfolio/actions/workflows/Commit.yml)

Personal portfolio website showcasing software projects. Features project cards with GitHub CI status, issue breakdowns, build history charts, and media galleries. Includes admin features for managing portfolio content.

## Components

| Component | Type | Description |
|-----------|------|-------------|
| Portfolio | React 19 SPA | Frontend built with TypeScript, Vite, and Material UI |
| Portfolio.Proxy | Node.js/Express | Backend proxy for authentication, session management, and media handling |

## Tech Stack

| Technology | Version |
|------------|---------|
| React | 19 |
| TypeScript | 5.8 |
| Bundler | Vite |
| UI Framework | Material UI |
| Backend | Node.js / Express |
